Open-issue assessment — 2026-09-23
================================

Update, 2026-09-24: the nine application/code issues below have now been
implemented locally. See [application fixes and deployment settings](application-fixes.md).
The tables below preserve the original assessment. PR #113 was already merged
on GitHub and has been pulled into the working branch; that merge also removed
the opencode workflow referenced in the original #87 assessment.

Reviewed all **28 open GitHub issues**, including their comments, against branch
`czupel` at `28f3dee235258a1c334fa932c5298dacfcc24805`. The remote branch had the
same revision when checked. This is a source review, not verification of the
running installation or an exploit test. GitHub issues were not changed.

Here, “fix now in code” means an implementation in this repository with tests
and a normal deployment. Small application settings and dependency changes
count; new infrastructure, credential rotation, provisioning, changes to the
authentication model, and physical safety decisions do not. Firmware fixes are
listed separately because applying them requires flashing and device checks.
Effort labels describe relative scope, not time estimates.
